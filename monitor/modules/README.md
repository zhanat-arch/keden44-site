# Frontend modules

- core/dt.js: номера ДТ, КДТ, статусы, даты, сортировка.
- keden/parser.js: парсинг видимого текста/ответов KEDEN.
- pdf/qr.js: чтение PDF и QR.
- storage/local.js: сохранение данных локально.
- ui/components.js: карточки, колонки, модальные окна.
- ui/actions.js: обработчики кнопок.
- themes/*.css: внешний вид без бизнес-логики.

Правило: новая функция сначала идёт в свой модуль, а app.js только связывает модули.
