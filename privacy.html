Политика конфиденциальности

KEDEN44 — независимый сервис для специалистов по таможенному оформлению. Он не является частью ИС «KEDEN», Комитета государственных доходов или другого государственного органа. По вопросам данных обратитесь через центр помощи KEDEN44.

Какие данные используются

Расширение может читать номер и видимые поля открытой пользователем ДТ, строки графы 44 и доступные организации уведомления KEDEN. Эти данные нужны только для сопоставления файлов, передачи выбранной ДТ в Монитор и показа статусов.

Выбранные PDF, JPEG и PNG обрабатываются локально в браузере. Подготовленные файлы передаются непосредственно в текущую авторизованную сессию KEDEN по команде пользователя. KEDEN44 не получает пароль KEDEN, ключ ЭЦП, пароль к ЭЦП, полный номер банковской карты или CVV.

При добровольном входе через Google сохраняются идентификатор Google-аккаунта, адрес электронной почты, имя и изображение профиля. Это нужно для входа и синхронизации устройств. При подключении Telegram сохраняются технические идентификаторы чата, список отслеживаемых ДТ и содержание добровольно отправленных обращений в поддержку. Для проверки платежа могут использоваться сумма, валюта, время оплаты, получения письма и отправки заявки, статус, имя и email аккаунта покупателя в Boosty и сведения из подтверждения покупки. Заявки и письма автоматически сопоставляются в течение 24 часов; неоднозначные случаи сохраняются для ручной проверки. Данные карты для сверки не запрашиваются.

Поддержание сессии и активность

При включении функции «Держать сессию» расширение локально определяет факт активности в открытой странице KEDEN: движение мыши, нажатие кнопки мыши, клавиши, прокрутку или касание. Это нужно, чтобы приостанавливать автоматические действия, когда пользователь работает. Сохраняются время последней активности и события смены состояния. Координаты мыши, содержимое нажатий клавиш и история отдельных кликов не записываются и не передаются на сервер. Активность в других приложениях не отслеживается.

Техническая диагностика и подключение

Для диагностики работы расширение передаёт серверу KEDEN44 технический идентификатор установки, версию и канал сборки, время проверки, интервал между проверками, результат и причину ошибки. Это используется для обнаружения сбоев и оценки работоспособности сервиса, а не для записи действий пользователя. Для проверки доступа, синхронизации и доставки уведомлений используются идентификатор аккаунта и служебный секрет устройства. Эти сведения не являются паролем KEDEN или ключом ЭЦП. Диагностика не содержит записи движений мыши, текста вводимых клавиш или истории кликов; сведения ДТ и уведомлений обрабатываются отдельно для заявленных функций.

Буфер обмена и журнал

По нажатию кнопки «Копировать весь лог» расширение запрашивает необязательное разрешение clipboardWrite и записывает журнал поддержания сессии в буфер обмена. Существующее содержимое буфера обмена не читается. Если автоматическое копирование недоступно, текст журнала показывается для ручного копирования. Само копирование не отправляет журнал на сервер; передача скопированного текста другому человеку или в поддержку выполняется пользователем отдельно. Локальный журнал поддержания сессии хранит события за последние семь дней.

Цели обработки

Данные используются для работы заявленных функций: прикрепления документов, Монитора, синхронизации, уведомлений, проверки доступа, поддержки и защиты сервиса. Данные не продаются и не используются для принятия решений государственными органами.

Аналитика и реклама

Сайт может использовать Google Analytics для общей статистики посещений. В аналитические события не отправляются номера ДТ, БИН, QR-ссылки, сведения о товарах и транспорте, названия или содержимое файлов.

Расширение может показывать явно обозначенные материалы KEDEN44, рекламу или партнёрские предложения. Для персонализации рекламы не используются данные Google, Telegram, ДТ, документов, платежей или уведомлений. Рекламная ссылка открывается только после действия пользователя.

Передача третьим сторонам

Данные передаются Google, Telegram, KEDEN и платёжным площадкам только в объёме, необходимом для выбранной пользователем функции. Работа этих сервисов регулируется их собственными условиями. Иная передача возможна при законном требовании или для предотвращения злоупотреблений.

Хранение и удаление

Локальные данные хранятся в браузере до очистки пользователем. Синхронизированные настройки, связи Telegram, статусы доступа и техническая активность хранятся на защищённом сервере, пока пользователь использует соответствующие функции или пока это необходимо для безопасности и учёта платежей. Для удаления облачных данных отправьте запрос через центр помощи из Telegram-аккаунта, связанного с KEDEN44.

Безопасность и Google API

Сетевой обмен выполняется по HTTPS, а чувствительные серверные связи защищаются при хранении. Использование информации, полученной через Google API, соответствует Chrome Web Store User Data Policy, включая требования Limited Use.

Изменения

Политика может обновляться вместе с функциями продукта. Актуальная редакция всегда публикуется на этой странице.
