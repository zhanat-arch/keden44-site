Политика конфиденциальности

KEDEN44 — независимый сервис для специалистов по таможенному оформлению. Он не является частью ИС «KEDEN», Комитета государственных доходов или другого государственного органа. По вопросам данных напишите на ezhanat@gmail.com.

Какие данные используются

Расширение может читать номер и видимые поля открытой пользователем ДТ, строки графы 44 и доступные организации уведомления KEDEN. Эти данные нужны только для сопоставления файлов, передачи выбранной ДТ в Монитор и показа статусов.

Выбранные PDF, JPEG и PNG обрабатываются локально в браузере. Подготовленные файлы передаются непосредственно в текущую авторизованную сессию KEDEN по команде пользователя. KEDEN44 не получает пароль KEDEN, ключ ЭЦП, пароль к ЭЦП, полный номер банковской карты или CVV.

При добровольном входе через Google сохраняются идентификатор Google-аккаунта, адрес электронной почты, имя и изображение профиля. Это нужно для входа и синхронизации устройств. При подключении Telegram сохраняются технические идентификаторы чата и список отслеживаемых ДТ. Для проверки платежа могут использоваться сумма, валюта, время, статус и последние четыре цифры карты.

Цели обработки

Данные используются для работы заявленных функций: прикрепления документов, Монитора, синхронизации, уведомлений, проверки доступа, поддержки и защиты сервиса. Данные не продаются и не используются для принятия решений государственными органами.

Аналитика и реклама

Сайт может использовать Google Analytics для общей статистики посещений. В аналитические события не отправляются номера ДТ, БИН, QR-ссылки, сведения о товарах и транспорте, названия или содержимое файлов.

Расширение может показывать явно обозначенные материалы KEDEN44, рекламу или партнёрские предложения. Для персонализации рекламы не используются данные Google, Telegram, ДТ, документов, платежей или уведомлений. Рекламная ссылка открывается только после действия пользователя.

Передача третьим сторонам

Данные передаются Google, Telegram, KEDEN и платёжным площадкам только в объёме, необходимом для выбранной пользователем функции. Работа этих сервисов регулируется их собственными условиями. Иная передача возможна при законном требовании или для предотвращения злоупотреблений.

Хранение и удаление

Локальные данные хранятся в браузере до очистки пользователем. Синхронизированные настройки, связи Telegram, статусы доступа и техническая активность хранятся на защищённом сервере, пока пользователь использует соответствующие функции или пока это необходимо для безопасности и учёта платежей. Для удаления облачных данных отправьте запрос с привязанного адреса на ezhanat@gmail.com.

Безопасность и Google API

Сетевой обмен выполняется по HTTPS, а чувствительные серверные связи защищаются при хранении. Использование информации, полученной через Google API, соответствует Chrome Web Store User Data Policy, включая требования Limited Use.

Изменения

Политика может обновляться вместе с функциями продукта. Актуальная редакция всегда публикуется на этой странице.
